# SrShadowy

**Self-taught developer focused on software, tools, game modding, and Linux.**

I've been programming since I was 10, learning primarily through experimentation, documentation, courses, and personal projects.

My interests have evolved from desktop applications into **C/C++, Lua, Python, Linux tooling, game modding, frameworks, and local/offline software**.

I enjoy building things that solve actual problems — especially tools that give users more control over their software and games.

- **C / C++** — native applications, systems and game-related tooling
- **Lua** — scripting, modding and frameworks
- **Python** — automation, tooling and desktop applications
- **C# / PHP / JavaScript** — application and web development
- **Linux / Windows** — development, system administration and troubleshooting
- **Qt / PySide6** — desktop applications and interfaces
- **Git / CMake** — development and build systems
- **game modding, emulation, graphics and local AI**
